## 캡처 전 확인

이 저장소는 포트폴리오 공개용입니다. 아래는 가리고 캡처하세요.

- 자사 실매출·실단가 등 구체 금액

수치는 지우기보다 **비율·순위만 남기거나 임의값으로 교체**하면 화면 구성은 보여주면서 정보는 보호할 수 있습니다.
