# 수동 전용 스크립트

여기 있는 파일은 **import 되는 순간 운영 DB 에 쓴다.** 모듈 최상위에서
`ALTER TABLE`, `init_db()`, 대량 조회를 바로 실행하기 때문이다.

그래서 `scripts/` 밖으로 빼 두었다.

- `test_*` 라는 이름이었던 파일은 `manual_*` 로 바꿨다. pytest 가
  `test_*.py` 를 자동 수집하는데, 수집만 해도 최상위 코드가 실행된다.
  (운영 DB 에 DDL 이 나간다는 뜻이다.)
- 돌릴 때는 무엇을 하는 스크립트인지 먼저 읽고, 직접 실행한다.

`cleanup_subcategories.py` 는 scripts/ 에 그대로 두되 `--yes` 를 요구하도록
고쳤다 (기본은 삭제 대상 건수만 보여준다).
